## Purpose
Configures GitHub Copilot suggestions without automatic prompts.

## Plugins
- `zbirenbaum/copilot.lua`

## Configuration
- Suggestions disabled by default and not auto-triggered.
- Keymaps: next `<M-]>`, prev `<M-[>`, dismiss `<C-]>`.
- Panel and cmp integration disabled.
