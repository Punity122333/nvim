# tools/trouble.lua

Source: `lua/plugins/tools/trouble.lua`

## Purpose
Diagnostics list UI with a safer jump action.

## Plugins
- `folke/trouble.nvim`

## Configuration
- Ensures target line exists before jumping.
- Keymaps: `<leader>xx` toggle diagnostics, `<leader>xX` buffer diagnostics.
- Command: `Trouble`.
