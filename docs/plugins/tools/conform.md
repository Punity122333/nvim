# tools/conform.lua

Source: `lua/plugins/tools/conform.lua`

## Purpose
Formatter orchestration for multiple languages.

## Plugins
- `stevearc/conform.nvim`

## Configuration
- Formatters mapped for Lua, C/C++, Python, JS/TS, Go, Haskell, Java, JSON, Kotlin, Markdown, PHP, R, Ruby, Rust, SQL, Svelte, Tailwind, TeX, TOML, YAML.
- `format_on_save = false`.
- Exposes `ConformInfo` command.
