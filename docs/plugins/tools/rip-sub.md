# tools/rip-sub.lua

Source: `lua/plugins/tools/rip-sub.lua`

## Purpose
Interactive search and replace with preview.

## Plugins
- `chrisgrieser/nvim-rip-substitute`

## Configuration
- Keymaps: `<leader>rs` and `<leader>rg` (normal/visual).
- Popup is top-aligned with rounded border and custom keymaps for confirm/abort.
- Incremental preview with 100ms debounce.
