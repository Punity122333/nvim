# tools/spider.lua

Source: `lua/plugins/tools/spider.lua`

## Purpose
Sub-word motions and operator helpers.

## Plugins
- `chrisgrieser/nvim-spider`

## Configuration
- Remaps `w`, `e`, `b` to spider motions in normal/visual.
- Adds `dp*`, `cp*`, `yp*`, `vp*` variants for delete/change/yank/select by sub-word.
