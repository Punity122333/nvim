# tools/dap-virtual-text.lua

Source: `lua/plugins/tools/dap-virtual-text.lua`

## Purpose
Shows inline variable values while debugging.

## Plugins
- `theHamsta/nvim-dap-virtual-text`

## Configuration
- Virtual text positioned at end-of-line.
- Shows stop reason and highlights changed variables.
- Custom display callback shows `name = value`.
