# tools/toggleterm.lua

Source: `lua/plugins/tools/toggleterm.lua`

## Purpose
Terminal management with floating terminals and custom highlights.

## Plugins
- `akinsho/toggleterm.nvim`

## Configuration
- Default open mapping `<c-\>` with floating rounded border.
- Terminal backgrounds set to `#1a1b26` with custom border color.
- Automatically closes terminal on clean exit.
