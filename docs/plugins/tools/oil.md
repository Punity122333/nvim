# tools/oil.lua

Source: `lua/plugins/tools/oil.lua`

## Purpose
File explorer with a toggleable sidebar and custom keymaps.

## Plugins
- `stevearc/oil.nvim`

## Configuration
- `-` toggles Oil in a right vertical split (width 41).
- Disables default file explorer and confirmations for simple edits.
- Custom window options and keymaps for window navigation and multicursor helpers.
- Hides statusline/winbar in Oil buffers and refreshes lualine on close.
