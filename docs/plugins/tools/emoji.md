# tools/emoji.lua

Source: `lua/plugins/tools/emoji.lua`

## Purpose
Adds emoji completion and Telescope search.

## Plugins
- `allaman/emoji.nvim`
- Dependencies: `plenary.nvim`, `nvim-cmp`, `telescope.nvim`.

## Configuration
- Enabled for `markdown` and `text` filetypes.
- Enables cmp integration.
- Loads Telescope extension and maps `<leader>se` to emoji picker.
