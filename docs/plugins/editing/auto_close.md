# editing/auto_close.lua

Source: `lua/plugins/editing/auto_close.lua`

## Purpose
Automatically closes and renames HTML/XML-style tags for web filetypes.

## Plugins
- `windwp/nvim-ts-autotag`

## Configuration
- Filetypes: `html`, `javascript`, `typescript`, `javascriptreact`, `typescriptreact`, `xml`, `css`.
- Enables auto close, auto rename, and close-on-slash behavior via `nvim-ts-autotag`.
