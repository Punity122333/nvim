# editing/vimtex.lua

Source: `lua/plugins/editing/vimtex.lua`

## Purpose
Provides LaTeX tooling with strict conceal and indent control.

## Plugins
- `lervag/vimtex`

## Configuration
- Disables all syntax concealment and enables syntax.
- Enables VimTeX indentation with custom lists and section commands.
- Disables the default insert mapping `]]` to avoid input lag.
