# editing/swap.lua

Source: `lua/plugins/editing/swap.lua`

## Purpose
Swaps words, opposites, chains, and case with quick mappings.

## Plugins
- `tigion/swap.nvim`

## Configuration
- Keymaps:
  - `<leader>Ci` swap word
  - `<leader>Co` swap opposite
  - `<leader>Cn` swap next
  - `<leader>Cc` swap case
- Uses default `swap.nvim` setup options.
