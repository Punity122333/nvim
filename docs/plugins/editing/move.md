# editing/move.lua

Source: `lua/plugins/editing/move.lua`

## Purpose
Adds moving text and lines with Alt-based mappings.

## Plugins
- `nvim-mini/mini.move`

## Configuration
- Mappings: `<A-h/j/k/l>` for moving, `<A-S-h/j/k/l>` for moving lines.
- `reindent_linewise = false` to avoid line reindent on move.
