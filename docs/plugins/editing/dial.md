# editing/dial.lua

Source: `lua/plugins/editing/dial.lua`

## Purpose
Provides increment/decrement "dial" targets for numbers and booleans.

## Plugins
- `monaqa/dial.nvim`

## Configuration
- Registers augend groups with decimal, hex, octal, binary integers and booleans.
- Applies the same augend set to `default` and `cpp` groups.
