# editing/various-textobjs.lua

Source: `lua/plugins/various-textobjs.lua`

## Purpose
Adds many extra textobjects with custom keymaps defined elsewhere.

## Plugins
- `chrisgrieser/nvim-various-textobjs`

## Configuration
- Default keymaps disabled (`useDefaultKeymaps = false`).
- Custom mappings live in `lua/modules/system/keymaps/plugins/textobjects.lua`.
