# lsp/fidget.lua

Source: `lua/plugins/lsp/fidget.lua`

## Purpose
Shows LSP progress and notifications with lightweight UI.

## Plugins
- `j-hui/fidget.nvim`

## Configuration
- Progress display uses `dots` spinner and a minimal single-line layout.
- Notifications are aligned top with small window size and no notify override.
- Safe require/setup with error logging to `~/.cache/fidget_*_error.log`.
