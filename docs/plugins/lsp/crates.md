# lsp/crates.lua

Source: `lua/plugins/lsp/crates.lua`

## Purpose
Enhances Cargo.toml editing with crate info, updates, and LSP integration.

## Plugins
- `saecki/crates.nvim`

## Configuration
- Auto loads on `Cargo.toml` reads.
- Enables auto update checks and LSP actions/completion/hover.
- Custom popup styling with rounded borders.
- Defines pill-style highlight groups for crate status.
