# lsp/diagnostics.lua

Source: `lua/plugins/lsp/diagnostics.lua`

## Purpose
Disables animation and scroll effects that conflict with diagnostics UX.

## Plugins
- `snacks.nvim`
- `nvim-mini/mini.animate` (disabled)

## Configuration
- Disables `snacks` scroll effects.
- Disables `mini.animate` entirely.
