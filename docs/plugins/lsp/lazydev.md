# lsp/lazydev.lua

Source: `lua/plugins/lsp/lazydev.lua`

## Purpose
Improves Lua development by adding library type information.

## Plugins
- `folke/lazydev.nvim`

## Configuration
- Enabled for `lua` filetypes and via `LazyDev` command.
- Adds library paths for `luvit-meta`, `love2d`, `busted`, and `LazyVim`.
- Respects `vim.g.lazydev_enabled` toggle.
