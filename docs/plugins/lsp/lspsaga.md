# lsp/lspsaga.lua

Source: `lua/plugins/lsp/lspsaga.lua`

## Purpose
Adds enhanced LSP UI (hover, finder, outline, diagnostics).

## Plugins
- `nvimdev/lspsaga.nvim`
- `nvim-treesitter/nvim-treesitter` (dependency)
- `nvim-tree/nvim-web-devicons` (dependency)

## Configuration
- UI: rounded borders with devicons.
- Disables winbar symbols, lightbulb, and beacon.
- Outline auto preview disabled.
- Loads on `LspAttach`.
