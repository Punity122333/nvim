# misc/snacks.lua

Source: `lua/plugins/misc/snacks.lua`

## Purpose
Enables Snacks UI components like explorer, picker, input, and scratch.

## Plugins
- `folke/snacks.nvim`

## Configuration
- Scratch window centered with fixed size and no backdrop.
- Explorer enabled on the right with narrow width and follow mode.
- Picker enabled with custom icons, no preview, and grep throttling.
- Input enabled; scroll/words/statuscolumn disabled.
- Image rendering enabled (math disabled).
- `<leader>e` toggles the explorer.
