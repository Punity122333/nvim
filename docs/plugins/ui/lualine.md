# ui/lualine.lua

Source: `lua/plugins/ui/lualine.lua`

## Purpose
Statusline configuration with snippet state awareness.

## Plugins
- `nvim-lualine/lualine.nvim`

## Configuration
- Enables global statusline and slow refresh rate.
- `lualine_a` shows `SNIPPET` when the custom snippet engine is active.
- `lualine_z` shows current time (HH:MM).
