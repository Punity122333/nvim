# ui/rainbowfast.lua

Source: `lua/plugins/ui/rainbowfast.lua`

## Purpose
Rainbow highlighting for brackets and keywords.

## Plugins
- `Punity122333/rainbow-fast.nvim`

## Configuration
- Brackets enabled; keywords disabled by default.
- Reuses Bash keyword config for sh/zsh.
- Keymaps: `<leader>rr` toggle all, `<leader>rj` toggle brackets, `<leader>rk` toggle keywords.
